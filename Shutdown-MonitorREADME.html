Shutdown-Monitor.ps1 — README

Overview

Shutdown-Monitor.ps1 is a PowerShell script designed to run on a second machine that is powered by the same UPS as a first machine running Monitor-UPS.ps1 --Server.

It connects to the UPS monitor server over TCP, retrieves JSON status, and:

  • Detects when AC power is lost (Status = "On Battery").
  • Starts a shutdown countdown (default 5 minutes).
  • Cancels shutdown if AC power returns before countdown ends.
  • Initiates shutdown if countdown expires.
  • Optionally logs power events and shutdown actions to C:\UPS\shutdown-monitor.log.

Features

  • Monitors UPS status remotely via TCP.
  • Configurable check interval and shutdown delay.
  • Optional logging of power events.
  • Can run interactively or in the background.

Parameters

ParameterTypeDefaultDescription
-ServerIPString"192.168.1.50"IP address of the first machine running Monitor-UPS.ps1 --Server.
-PortInteger50000TCP port of the UPS monitor server.
-CheckIntervalInteger30Seconds between status checks.
-ShutdownDelayInteger300Seconds to wait before shutdown after going on battery.
-LogSwitch(off)Enable logging to C:\UPS\shutdown-monitor.log.

Logging

When -Log is specified:

  • Creates C:\UPS folder if missing.
  • Creates shutdown-monitor.log if missing.
  • Writes timestamped entries when:
    • Power failure is detected.
    • Shutdown is initiated.
    • Shutdown is canceled.

Example log entries:

2026-08-16 15:02:10 Power failure detected. Shutdown scheduled in 300 seconds unless power returns.
2026-08-16 15:07:15 Shutdown initiated after 300 seconds on battery.

Usage Examples

1. Start in Interactive Mode

Runs in the current PowerShell window and displays status messages.

.\Shutdown-Monitor.ps1 -ServerIP "192.168.1.50" -Port 50000 -CheckInterval 30 -ShutdownDelay 300 -Log

2. Start in Background (Detached)

Runs without tying up your current PowerShell session.

Start-Job -ScriptBlock {
    & "C:\Path\To\Shutdown-Monitor.ps1" -ServerIP "192.168.1.50" -Port 50000 -CheckInterval 30 -ShutdownDelay 300 -Log
}

The job will keep running until the session ends or the job is stopped.

To see running jobs:

Get-Job

To stop a job:

Stop-Job -Id <JobId>

3. Start as a Scheduled Task (Recommended for Always-On Monitoring)

  1. Open Task Scheduler.
  2. Create a new task:
    • Trigger: At startup or at logon.
    • Action: 
      powershell.exe -ExecutionPolicy Bypass -File "C:\Path\To\Shutdown-Monitor.ps1" -ServerIP "192.168.1.50" -Port 50000 -CheckInterval 30 -ShutdownDelay 300 -Log
    • Run with highest privileges (required for shutdown).
  3. Save and enable the task.

Shutdown Logic

  1. If Status = "On Battery":
    • Start countdown (ShutdownDelay seconds).
    • If AC returns before countdown ends → cancel shutdown.
    • If countdown expires → run: 
      Stop-Computer -Force
  2. If Status = "Online":
    • Cancel any pending shutdown.

Requirements

  • Windows with PowerShell 5.1 or later.
