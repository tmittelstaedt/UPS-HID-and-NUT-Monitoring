UPS Monitor for Ubuntu (GNOME)

This Python 3 script monitors an APC UPS via /usr/sbin/apcaccess and integrates with the GNOME desktop. It displays a top-bar AppIndicator icon that changes color based on UPS status, flashes red when on battery, and provides a dropdown menu with live UPS stats. Icons are generated with ImageMagick and optionally can include the text UPS for clarity.

Features

  • Runs /usr/sbin/apcaccess every 60 seconds
  • Top-bar icon color:
    • Green – UPS online (mains power)
    • Flashing Red – UPS on battery or low battery (alternates between solid red and transparent red text)
    • Grey – Unknown status or communication lost
  • Desktop notifications when status changes
  • Dropdown menu shows:
    • MODEL
    • LINEV
    • LOADPCT
    • BCHARGE
    • BATTV
    • TIMELEFT
  • Manual “Refresh Now” option in menu
  • Quit option in menu

Requirements

Install the following packages:

sudo apt install python3-gi gir1.2-gtk-3.0 gir1.2-appindicator3-0.1 libnotify-bin apcupsd imagemagick

Installation

  1. Ensure apcupsd is installed and configured so that /usr/sbin/apcaccess works.
  2. Place the script apc_ups_monitor.py in your preferred directory.
  3. Generate the icons with centered text with ImageMagick:
# Green icon (UPS online)
convert -size 48x48 xc:green \
    -gravity center \
    -pointsize 20 \
    -fill white \
    -font DejaVu-Sans-Bold \
    -annotate 0 "UPS" \
    icon_green.png

# Red icon (UPS on battery)
convert -size 48x48 xc:red \
    -gravity center \
    -pointsize 20 \
    -fill white \
    -font DejaVu-Sans-Bold \
    -annotate 0 "UPS" \
    icon_red.png

# Grey icon (UPS unknown)
convert -size 48x48 xc:grey \
    -gravity center \
    -pointsize 20 \
    -fill black \
    -font DejaVu-Sans-Bold \
    -annotate 0 "UPS" \
    icon_grey.png

# Transparent icon with red text (for flashing)
convert -size 48x48 xc:none \
    -gravity center \
    -pointsize 20 \
    -fill red \
    -font DejaVu-Sans-Bold \
    -annotate 0 "UPS" \
    icon_red_flash.png

    Usage

    chmod +x apc_ups_monitor.py
./apc_ups_monitor.py

    The icon will appear in the GNOME top bar. Click it to see UPS stats, refresh instantly, or quit.

    Behavior

    • Checks UPS status every 60 seconds automatically
    • Flashes red icon every second when on battery (solid red ↔ transparent red text)
    • Stops flashing when UPS returns to online or unknown state
    • Notifications are sent only when status changes

    Troubleshooting

    • If the icon does not appear, ensure GNOME’s “AppIndicator Support” extension is enabled.
    • If you see libayatana-appindicator is deprecated warning, it is harmless — GNOME still supports it.
    • If /usr/sbin/apcaccess fails, check that apcupsd is running and configured.
