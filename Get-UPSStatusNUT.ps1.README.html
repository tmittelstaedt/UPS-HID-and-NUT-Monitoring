📄 Using PowerShell to Query a NUT Server

1. Overview

This guide explains how to:

  • Configure a Network UPS Tools (NUT) server to allow remote access.
  • Use a PowerShell script to connect to the NUT server and retrieve UPS status.
  • Parse UPS variables into a structured format for monitoring.

The script uses the NUT TCP protocol (upsd) on port 3493 to send commands like LIST VAR <upsname> and read the results.

2. NUT Server Configuration

2.1 Install NUT (Linux Example)

# Debian/Ubuntu
sudo apt update
sudo apt install nut-server nut-client

# RHEL/CentOS
sudo dnf install nut

2.2 Configure UPS in ups.conf

[localups]
    driver = usbhid-ups
    port = auto
    desc = "My UPS"

2.3 Configure Access in upsd.conf

LISTEN 0.0.0.0 3493
LISTEN :: 3493

ACL myclient 192.168.1.0/24
ACCEPT myclient
REJECT all

2.4 Configure Users in upsd.users

[monuser]
    password = mypass
    upsmon master

2.5 Restart NUT

sudo systemctl enable nut-server
sudo systemctl restart nut-server

2.6 Test Locally

upsc localups@localhost

3. PowerShell Script

Save as Get-UPSStatusNUT.ps1:

param (
    [string]$NutServer = "192.168.1.100",
    [string]$UpsName = "localups",
    [int]$Port = 3493,
    [int]$TimeoutSeconds = 5,
    [string]$Username = "monuser",
    [string]$Password = "mypass"
)

try {
    $client = New-Object System.Net.Sockets.TcpClient
    $client.ReceiveTimeout = $TimeoutSeconds * 1000
    $client.SendTimeout = $TimeoutSeconds * 1000
    $client.Connect($NutServer, $Port)

    $stream = $client.GetStream()
    $reader = New-Object System.IO.StreamReader($stream)
    $writer = New-Object System.IO.StreamWriter($stream)
    $writer.AutoFlush = $true

    Write-Host "Connected to NUT server $NutServer on port $Port"

    if ($Username -and $Password) {
        $writer.WriteLine("USERNAME $Username")
        $writer.WriteLine("PASSWORD $Password")
        Start-Sleep -Milliseconds 200
    }

    $writer.WriteLine("LIST VAR $UpsName")
    Start-Sleep -Milliseconds 200

    $vars = @{}
    while ($stream.DataAvailable) {
        $line = $reader.ReadLine()
        if ($line -match '^VAR\s+\S+\s+(\S+)\s+"(.*)"$') {
            $vars[$matches[1]] = $matches[2]
        }
    }

    $upsStatus = [PSCustomObject]$vars

    Write-Host "`nUPS Status Object:" -ForegroundColor Cyan
    $upsStatus | Format-List

    Write-Host "`nBattery Charge: $($upsStatus.'battery.charge')%"
    Write-Host "UPS Status: $($upsStatus.'ups.status')"

    $writer.Close()
    $reader.Close()
    $client.Close()
}
catch {
    Write-Error "Failed to connect or retrieve data: $_"
}

4. Running the Script

powershell -ExecutionPolicy Bypass -File .\Get-UPSStatusNUT.ps1 `
    -NutServer "192.168.1.100" `
    -UpsName "localups" `
    -Username "monuser" `
    -Password "mypass"

6. Troubleshooting

ProblemCauseFix
No UPS devices foundLIST UPS disabled or IP not allowedUse known UPS name and update upsd.conf ACL
Connection refusedNUT server not listening on external IPAdd LISTEN 0.0.0.0 3493 to upsd.conf
Access deniedMissing or wrong credentialsUpdate upsd.users and script parameters
Script hangsFirewall blocking port 3493Allow TCP 3493 on server firewall

7. Security Considerations

  • Restrict NUT server access to trusted IP ranges in upsd.conf.
  • Always use a dedicated NUT user account with minimal privileges.
  • Do not expose port 3493 to the public internet without a VPN or firewall rules.
  • Store credentials securely — avoid hardcoding passwords in scripts if possible.

8. Optional: Logging UPS Data

You can log UPS status to a CSV file for historical tracking:

$upsStatus | Export-Csv -Path "UPS_Log.csv" -Append -NoTypeInformation

This allows you to graph battery charge, runtime, and other metrics over time.

9. Optional: Alerting on Low Battery

Example snippet to send an alert if battery charge drops below 30%:

if ([int]$upsStatus.'battery.charge' -lt 30) {
    Write-Warning "Battery charge is below 30%!"
    # Example: Send email (requires configured SMTP)
    Send-MailMessage -To "admin@example.com" -From "ups-monitor@example.com" `
        -Subject "UPS Low Battery Alert" `
        -Body "Battery charge is $($upsStatus.'battery.charge')%" `
        -SmtpServer "mail.example.com"
}
