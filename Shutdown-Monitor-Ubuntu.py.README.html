UPS Shutdown Monitor — Python Script for Ubuntu

Overview

This Python script runs on an Ubuntu system and monitors a UPS via a TCP connection to a Windows machine running: 

Monitor-UPS.ps1 --Server

It retrieves UPS status in JSON format and:

  • Detects when AC power is lost (Status = "On Battery").
  • Starts a 5‑minute shutdown countdown.
  • Cancels shutdown if AC power returns before countdown ends.
  • Initiates shutdown if countdown expires.
  • Optionally logs events to /var/log/ups-shutdown-monitor.log.

Features

  • Monitors UPS status remotely over TCP.
  • Configurable check interval and shutdown delay.
  • Optional logging of power events.
  • Can run manually, in the background, or as a systemd service.

Requirements

  • Ubuntu (or other Linux with Python 3 installed).
  • Root privileges for shutdown.
  • Network access to the Windows UPS monitor server.
  • Python 3.6+.

Script Configuration

At the top of the script, you can adjust:

VariableDefault ValueDescription
SERVER_IP"192.168.1.50"IP of the Windows UPS monitor server.
SERVER_PORT50000TCP port of the UPS monitor server.
CHECK_INTERVAL30Seconds between status checks.
SHUTDOWN_DELAY300Seconds to wait before shutdown after going on battery.
ENABLE_LOGTrueEnable/disable logging.
LOG_FILE"/var/log/ups-shutdown-monitor.log"Path to log file.

Installation Steps

1. Save the Script

nano shutdown_monitor.py

Paste the Python code, then save and exit.

2. Make it Executable

chmod +x shutdown_monitor.py

3. Run Manually

sudo ./shutdown_monitor.py

(Use sudo to allow shutdown and log writing to /var/log.)

4. Run in Background

nohup sudo ./shutdown_monitor.py &
  • nohup allows the script to keep running after you log out.
  • The & runs it in the background.

5. Run at Startup (systemd Service)

Create a systemd service file:

sudo nano /etc/systemd/system/ups-shutdown-monitor.service

Add:

[Unit]
Description=UPS Shutdown Monitor
After=network.target

[Service]
ExecStart=/usr/bin/python3 /path/to/shutdown_monitor.py
Restart=always
User=root

[Install]
WantedBy=multi-user.target

Replace /path/to/shutdown_monitor.py with the actual script path.

Enable and start the service:

sudo systemctl daemon-reload
sudo systemctl enable ups-shutdown-monitor
sudo systemctl start ups-shutdown-monitor

Logging

If ENABLE_LOG = True:

  • The script writes to /var/log/ups-shutdown-monitor.log.
  • Example log entries:
2026-08-16 15:02:10 Power failure detected. Shutdown scheduled in 300 seconds unless power returns.
2026-08-16 15:07:15 Shutdown initiated after 300 seconds on battery.

Shutdown Logic

  1. If Status = "On Battery":
    • Start countdown (SHUTDOWN_DELAY seconds).
    • If AC returns before countdown ends → cancel shutdown.
    • If countdown expires → run: 
      sudo shutdown -h now
  2. If Status = "Online":
    • Cancel any pending shutdown.

Security Notes

  • No authentication is used — only run on trusted LANs.
  • If exposing to the internet, use a firewall or VPN to restrict access.
  • Ensure only trusted users can modify the script or service file.
