UPS Monitor PowerShell Script – Documentation

1. Overview

The UPS Monitor PowerShell Script is a Windows-based utility that:

  • Monitors UPS (Uninterruptible Power Supply) status.
  • Works with local UPS devices via Windows WMI (Win32_Battery) or remote UPS devices via a Network UPS Tools (NUT) server.
  • Displays a system tray icon with color-coded status:
    • Green – UPS is online (AC power present)
    • Red – UPS is on battery
    • Gray – Status unknown
  • Optionally runs a TCP server to provide UPS status in JSON format for remote monitoring.
  • Can initiate a system shutdown if AC power is lost for a configurable delay.

2. Features

FeatureDescription
Tray IconShows UPS status with color coding and tooltip text.
Local UPS SupportUses Windows WMI to read battery status.
NUT Server SupportQueries a remote UPS via TCP port 3493.
Shutdown TimerAutomatically shuts down the system after a set delay if AC power is lost.
TCP Status ServerServes UPS status as JSON for integration with other tools.
Resource CleanupDisposes of icons and stops TCP listener on exit.

3. Requirements

  • Operating System: Windows 10, 11, or Windows Server with PowerShell 5.1+ or PowerShell 7.x.
  • Permissions: Administrator rights required for shutdown functionality.
  • Optional: Network UPS Tools (NUT) server for remote UPS monitoring.

5. How It Works

  1. Initialization – Loads .NET assemblies, creates tray icon, starts timer.
  2. Status Check – Queries NUT server or local UPS via WMI.
  3. Tray Icon Update – Changes icon color and tooltip.
  4. Shutdown Logic – Starts countdown on AC loss, shuts down if delay expires.
  5. TCP Server – Sends UPS status as JSON.
  6. Cleanup – Disposes icons and stops TCP listener.

6. Running the Script

Set-ExecutionPolicy RemoteSigned -Scope Process
.\UPSMonitor.ps1

or

To run the script without changing your system-wide execution policy and keep it running in the background:

powershell -ExecutionPolicy Bypass -WindowStyle Hidden -File "C:\Path\To\Monitor-UPS.ps1" -NutServer "192.168.1.50" -UpsName "myups"

or

Run in Tray Mode Only

.\Monitor-UPS.ps1

Displays UPS status in the system tray. No network access is provided.

Run in Tray + TCP Server Mode

.\Monitor-UPS.ps1 --Server

Displays UPS status in the system tray and opens a TCP listener on port 50000 (unreserved high port). Allows remote clients to connect and retrieve UPS status in JSON format.

Parameters:

  • -NutServer "<IP or hostname>" → IP or hostname of the NUT server
  • -UpsName "<UPS name>" → UPS name configured on the NUT server
  • -Server → (Optional) Enable JSON TCP server (local UPS mode only)

Examples:

NUT mode:

powershell -ExecutionPolicy Bypass -WindowStyle Hidden -File "C:\Scripts\Monitor-UPS.ps1" -NutServer "172.16.16.20" -UpsName "localups"

Local UPS mode with JSON server:

powershell -ExecutionPolicy Bypass -WindowStyle Hidden -File "C:\Scripts\Monitor-UPS.ps1" -Server

TCP Server Details

  • Port: 50000 (can be changed in the script).
  • Protocol: TCP (plain text JSON over UTF-8).
  • Connection Model: One-shot — client connects, receives one JSON object, then connection closes.
  • Security: No authentication. Intended for trusted LAN environments only.

7. Example TCP JSON Output

When -Server is used in local UPS mode, the script starts a TCP listener on port 50000. Any TCP client can connect and receive a single JSON object with the current UPS status.

{
  "UPSName": "Local UPS",
  "Status": "Online",
  "BatteryPercent": "100",
  "EstimatedRunTime": 120,
  "ChargingStatus": "Charging",
  "TimeToFull": "00:30:00",
  "TimestampUTC": "2026-08-21T12:34:56Z"
}

Field Descriptions

FieldTypeDescription
UPSNameStringFriendly name of the UPS (mapped from VendorID/ProductID if known).
StatusString"Online", "On Battery", or "Unknown".
BatteryPercentInteger or nullBattery charge percentage (0–100). null if unknown.
TimestampUTCStringISO 8601 UTC timestamp when the reading was taken.

Example Client Queries

Using PowerShell

$tcpClient = New-Object System.Net.Sockets.TcpClient("192.168.1.50", 50000)
$stream = $tcpClient.GetStream()
$reader = New-Object System.IO.StreamReader($stream)
$json = $reader.ReadToEnd()
$tcpClient.Close()

$data = $json | ConvertFrom-Json
$data

Using Netcat

nc 192.168.1.50 50000

Shutdown Delay Behavior

  • If AC power is lost (Status = "On Battery"), the script starts a 5-minute countdown.
  • If AC power returns before the countdown ends, shutdown is canceled.
  • If AC power remains offline for the full 5 minutes, the script issues: 
    Stop-Computer -Force
    (Requires administrator privileges.)

9. Notes

  • Requires PowerShell 5.1 or later.
  • In NUT mode, ensure TCP port 3493 is open between the client and server.
  • The JSON TCP server is only available in local UPS mode.
  • The tray icon updates every 5 seconds (configurable in $timer.Interval).

10. Safety Notes

  • Test without shutdown enabled before production use.
  • Set $shutdownDelaySeconds appropriately to avoid accidental shutdowns.
  • Secure TCP port with firewall rules if enabled.
